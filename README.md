# Projetos das crianças · Educação Tecnológica Paula Peclat

Site em [paulapeclat.github.io](https://paulapeclat.github.io) com os jogos, apps e projetos de IA criados nas aulas online de criação de tecnologias digitais para crianças.

## Como pôr um projeto novo

1. Peça autorização da família.
2. Salve um print do projeto (nunca foto do rosto) em `assets/projetos/`.
3. Acrescente o projeto em `data/projetos.json`, seguindo o `_exemplo`, só com o primeiro nome da criança.
4. Comite. O workflow gera a página e publica sozinho.

## Primeira vez

Em **Settings → Pages**, escolha **Source: GitHub Actions**.
